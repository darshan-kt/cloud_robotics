# cloud-container/frontend/

**Purpose:** the operator console — a React + TypeScript + Tailwind single-page app.

**Will contain:**
- **Dashboard** page — fleet overview
- **Robot** page — live camera (WebRTC), arrow-button + keyboard teleop (throttled to 20Hz), connection status, robot state, battery, velocity, emergency stop
- **Settings** page
- **Health** page
- A typed API client for the backend REST/WebSocket endpoints

**Filled in:** Milestone 9.
