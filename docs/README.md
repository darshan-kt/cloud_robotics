# Learning Path

This folder is the running curriculum for this project. Every milestone adds one numbered doc here, written so that reading them in order teaches you cloud robotics architecture concept by concept — not just what was typed, but **why** it was built that way and **what it does for you**.

Each doc follows the same three-part shape:

- **What this step is** — the concept or component being introduced
- **Why it's needed** — the problem it solves, and why the "obvious simpler" alternative wasn't chosen
- **What it does** — concretely, in this codebase
